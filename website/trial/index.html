First run: local demo only

Open two PowerShell windows in the extracted folder. In the first, start the server. In the second, run the example. If policy blocks execution, use your organization's approved process; do not disable protection.

The demo binds to 127.0.0.1. Stop it with Ctrl+C. Read docs/CONFIGURATION.md before considering a real target.

# Window 1
powershell -File .\examples\Start-DemoServer.ps1

# Window 2
.\RABBITX.exe --config .\examples\rabbitx.example.json --html --output .\trial-local.html

What results mean

Configuration observations, aggregated rule groups and unverified risk candidates are distinct from manually confirmed vulnerabilities. All three synthetic QA cases had zero confirmed vulnerabilities. Zero findings does not establish security. This is fetched-response discovery, not a full JavaScript browser crawler.

AI triage is an optional offline Mock demonstration, not a live model. It does not execute recommendations. No real customer results, guaranteed vulnerability discovery or distinct delivered paid-analysis capability are claimed.

Authorized assets only

Use owned or explicitly authorized test environments. Agree on hosts, paths, methods, request limits and stop conditions first. Do not scan arbitrary public systems. Stop on rate limiting, service trouble, unexpected sensitive data or revoked authorization.
