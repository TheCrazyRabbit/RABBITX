Know the Beta boundaries

Discovery uses fetched responses; RABBITX does not execute application JavaScript or act as a full browser crawler. Configuration observations and unverified risk candidates are not confirmed vulnerabilities. AI triage is an offline Mock; no live model service is enabled. Core audits and reports need no account login or payment.

Use only with explicit authorization. Respect target policies, scope, request and rate limits, disclosure rules, and any request to stop.

Paid subscriptions are currently unavailable. Project and HTML report features are available for free evaluation. The software is source-available under the repository’s Beta License; website terms do not replace that license.
