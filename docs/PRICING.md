# RABBITX Beta pricing test

**This is a proposal for willingness-to-pay research. Checkout and license enforcement are not active.**

## Free — proposed

- Basic endpoint and parameter inventory.
- Scope, request budget, and rate controls.
- JSON export.
- Local use on Windows.

## Pro — proposed at US$24/month

- Saved projects, audit history, resume, and replay.
- Standalone HTML reports and full evidence export.
- Higher configurable request budgets.
- v0.9 AI Triage when it is released.

The current v0.8 beta binary does not enforce these plan boundaries; its project and HTML features are available for evaluation. No payment should be collected until the plan and license flow are implemented and the offer is published with working terms and checkout.

## What we are validating

- Is endpoint prioritization useful enough to save time in a real, authorized review?
- Which report/project features are necessary for repeat use?
- Would a researcher pay US$24/month for the proposed Pro workflow?

See the recruitment drafts in [BETA_OUTREACH.md](BETA_OUTREACH.md). Do not treat this proposal as a live subscription offer.
